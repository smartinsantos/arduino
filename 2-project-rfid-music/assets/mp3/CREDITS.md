# Sample music

Each folder here is laid out exactly as it goes on the SD card: copy `01`, `02` and `03` to the root of the card, then run `dot_clean /Volumes/<card name>`.

The MP3 files are not in git (they're about 57 MB). To rebuild a folder, download each file from its source below and save it under the name in the first column.
